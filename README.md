# Rivoli

Espacio de trabajo para Rivoli Ristorante (Nueva de Lyon 79, Providencia, Santiago): prototipos web e ideas internas.

## Estructura

| Carpeta | Contenido |
|---|---|
| `carta/` | Portada ilustrada (Aestas) e índice de la carta en arcos, con categorías por sección. |
| `assets/` | Ilustraciones (Ianus, Sabinae, Aestas) y logos de Rivoli. |
| `tragos-verano/` | Visor móvil de los tragos de verano (Ianus, Sabina, Daiquiri). Se abre desde un QR. |
| `web-prueba/` | Página web de prueba del restaurante. |
| `ideas/` | Propuestas y material interno (documentos, visores, borradores). |

## Publicación

El sitio se publica con GitHub Pages desde la rama `main`.

- Carta: `https://rarubilar.github.io/RIVOLI/carta/`
- Tragos de verano: `https://rarubilar.github.io/RIVOLI/tragos-verano/`
- Un trago específico: agregar `#ianus`, `#sabina` o `#daiquiri` al final.

## Convenciones

- Cada proyecto vive en su propia carpeta con un `index.html`.
- Las versiones se marcan en el mensaje de commit (V01, V02…).
